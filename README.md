# Shaik Yasar Malik | Portfolio

Personal portfolio website of **Shaik Yasar Malik**, an aspiring Data Analyst and BI Analyst from Bengaluru, India. It shows my education, projects, skills and contact details in one fast, mobile-friendly page.

**Live site:** https://shaik-yasar-malik.github.io

## Features

- Dark, animated theme with smooth scrolling
- Fixed menu that highlights the section you are reading, plus a scroll progress bar
- "Next" buttons to move from one section to the next
- Fully responsive layout for phones, tablets and desktops
- Single-file website with no frameworks or build step, so it loads quickly

## Built with

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (scroll effects and active menu)
- Hosted on GitHub Pages

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in any web browser.

No installation is needed.
